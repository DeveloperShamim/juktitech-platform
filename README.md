# Jukti Tech Platform 🚀

**Jukti Tech (যুক্তি টেক)** — Ready-made Laravel Websites, Software & Digital Solutions Marketplace.

## Features
- **Ready-made Website Marketplace**: High converting Laravel e-commerce scripts, news portals, ERPs, LMS, POS, and digital portfolios.
- **Instant Digital Downloads**: Secure file delivery and Google Drive integration with download limits and tokens.
- **Client Portal & License Management**: Domain licensing, multi-tier packages, order tracking, and renewal system.
- **Payment & Automation**: Automated checkout, bKash/Nagad manual & gateway support, automated SMS and Courier API integrations.
- **Modern Apple-Clean Design**: Lightweight, 0.4s fast loading with custom responsive UI and interactive template switchers.

## Technology Stack
- **Backend**: Laravel (PHP 8.2+)
- **Database**: MySQL
- **Frontend**: Blade, HTML5, Modern CSS, Vanilla JS, Bootstrap

## Setup & Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/DeveloperShamim/juktitech-platform.git
   ```
2. Navigate to project directory:
   ```bash
   cd juktitech-platform/project
   ```
3. Install dependencies:
   ```bash
   composer install
   ```
4. Configure environment:
   ```bash
   cp .env.example .env
   php artisan key:generate
   ```
5. Migrate database:
   ```bash
   php artisan migrate --seed
   ```
6. Run the application:
   ```bash
   php artisan serve
   ```
